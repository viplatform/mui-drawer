# Dependabot review — 7 September 2026

Reviewed against the main branch. Dismissals are specific to the current dependency usage and must be reconsidered if the described input paths change.

- [Alert #78](https://github.com/viplatform/mui-drawer/security/dependabot/78) — `browserslist` ([GHSA-73wf-gq98-2v4g](https://github.com/advisories/GHSA-73wf-gq98-2v4g)): **upgrade**. Update to the patched release and verify dependency behavior.

- [Alert #76](https://github.com/viplatform/mui-drawer/security/dependabot/76) — `fast-uri` ([GHSA-jqff-g426-hqxp](https://github.com/advisories/GHSA-jqff-g426-hqxp)): **dismiss**. The locked fast-uri dependency is used by Ajv for JSON Schema URI/reference handling. This repository does not import fast-uri, accept untrusted schemas, or use Ajv URI normalization to authorize redirects or outbound destinations. The advisory requires attacker-controlled URLs reaching normalize/resolve before a host/origin/SSRF policy decision; that path is absent. Reassess if remote/untrusted schemas or URL-policy uses are introduced.
